# CoffeeShop

This Coffee Order System is a lightweight PHP and MySQL web application designed to manage a coffee shop catalog while providing role-based user experiences. It enables guests and registered customers to browse the menu and add items to a session-based order list, automatically applying an exclusive 10% discount to logged-in customers. Administrators have full access to create, edit, and delete coffee products, as well as manage users by viewing registrations and provisioning new staff or admin accounts. Built on Bootstrap with secure password_hash() authentication and session protection, the system runs locally on an Apache/MySQL environment like XAMPP by configuring config.php and seeding the initial administrator credentials.
